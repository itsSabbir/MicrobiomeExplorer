# MicrobiomeExplorer

Interactive Shiny dashboard for microbiome data analysis. Supports 16S rRNA,
metagenomic, and metatranscriptomic data with built-in statistical analysis,
visualization, and machine learning tools.

**Features:** Taxonomic composition, alpha/beta diversity, differential
expression (DESeq2/edgeR), correlation analysis, heatmaps, random forest
classification, network analysis, and more.

**Note:** The first load after inactivity may take 2-5 minutes while the
container restarts. A sample dataset is pre-loaded so you can explore
immediately.

Source: [github.com/itsSabbir/MicrobiomeExplorer](https://github.com/itsSabbir/MicrobiomeExplorer)
